# Месторождение Х

Браузерная 3D-игра для планшета: спроектируйте разработку нового месторождения (скважины, ППД, трубопроводы, ДНС, УПН) и получите максимальный ЧДД. Результаты попадают в общий рейтинг.

## Как поиграть на своём компьютере

Дважды щёлкните `start_local.bat`: откроется http://localhost:8000. Нужен установленный Python.
Если открыть `index.html` просто двойным щелчком, игра не запустится: браузер не грузит модули с диска.

## Публикация на GitHub Pages (бесплатно, без git)

1. На github.com нажмите **New repository**. Имя латиницей, например `field-x`, тип **Public**, затем **Create repository**.
2. На странице репозитория: **uploading an existing file** (или **Add file → Upload files**).
   Перетащите в окно **всё содержимое** этой папки: `index.html`, `.nojekyll`, папки `css` и `js` и остальные файлы. Нажмите **Commit changes**.
   Файл `.nojekyll` в Проводнике может быть скрыт; без него игра тоже работает.
3. **Settings → Pages → Build and deployment**: Source = **Deploy from a branch**, Branch = **main**, папка **/ (root)**, затем **Save**.
4. Через 1–2 минуты игра откроется по адресу `https://ВАШ-НИК.github.io/field-x/`. Эту ссылку и отправляйте друзьям.

Чтобы обновить игру, снова загрузите изменённые файлы через **Add file → Upload files**: сайт обновится сам.

На планшете откройте ссылку и выберите **«На экран "Домой"»**: игра будет запускаться как приложение, на весь экран.

## Общий онлайн-рейтинг (Supabase, бесплатно)

Пока рейтинг не настроен, результаты хранятся только в браузере каждого игрока. Чтобы таблица стала общей:

1. Зарегистрируйтесь на https://supabase.com (можно через GitHub) и нажмите **New project** (регион любой, например Frankfurt).
2. В проекте откройте **SQL Editor → New query**, вставьте содержимое `supabase.sql` и нажмите **Run**.
3. В **Project Settings → API** скопируйте **Project URL** и ключ **anon public**.
4. Вставьте их в `js/config.js`:
   ```js
   SUPABASE_URL: 'https://xxxxxxxx.supabase.co',
   SUPABASE_ANON_KEY: 'eyJhbGciOi...',
   ```
5. Загрузите обновлённый `js/config.js` на GitHub. В панели рейтинга появится зелёная точка «онлайн».

Ключ `anon` публичный, его можно хранить в открытом коде: правила в `supabase.sql` разрешают только читать и добавлять результаты.

## Устройство

| Файл | Что внутри |
|---|---|
| `js/scenarios.js` | Сценарии: геология, PVT, экономика, бюджет. Новое месторождение = новый объект в списке |
| `js/field.js` | Генерация сеточной модели пласта 40×40 ячеек по 100 м |
| `js/sim.js` | Сеть сбора, зоны дренирования, характеристика вытеснения, ЧДД, советы |
| `js/scene.js` | 3D-сцена (Three.js): карта, пласт, объекты, жесты |
| `js/main.js` | Интерфейс, палитра, расчёт, результаты |
| `js/leaderboard.js` | Рейтинг (Supabase или localStorage) |
| `js/glossary.js` | Термины с пояснениями |

Формулы расчёта описаны в игре: **📋 Паспорт → «Как считается»**.
